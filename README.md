# Housing in Mexico

## Project Overview
This project focuses on cleaning and preprocessing Mexico real estate data to prepare it for exploratory analysis and predictive modeling.

## Tasks Completed
- Handled missing values
- Split latitude and longitude coordinates
- Extracted location features
- Removed unnecessary columns
- Merged multiple datasets
- Exported a clean consolidated dataset

## Tools Used
- Python
- Pandas
- Jupyter Notebook

## Output
A clean, analysis-ready Mexico housing dataset.
